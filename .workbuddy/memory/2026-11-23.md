- `mvn test -q` 用 5.0.0 全绿（30/30）；日志可见 `.docx` 真实抽取成功、`.doc` 在无 scratchpad 时优雅降级为空。`README.md` 3.2 节同步说明依赖边界与 .doc 可选能力。
- 用户最终决定加回 `poi-scratchpad:5.0.0`（`poi` / `poi-ooxml` 仍 5.0.0）。`WordDataExtractor` 移除反射降级，`.doc` 恢复编译期直连 HWPF（`HWPFDocument` + `WordExtractor` + `TableIterator`），异常仍收敛为空列表。新增单测断言 `HWPFDocument` 在 classpath 上，防止依赖被误删后静默降级。`mvn test -q` 全绿（31/31），依赖树确认三包均为 5.0.0。README 同步更新。
